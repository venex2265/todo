# TodoMe

A responsive task dashboard built with plain HTML, CSS and JavaScript (no build step).

**Features:** tasks (add, edit, delete, complete, in-progress), filters, search, calendar with day filter,
quick notes, focus timer, analytics, notifications, light/dark theme, data saved in `localStorage`.

## Run it
Open `index.html` in a browser, or serve the folder (for example with the VS Code Live Server extension).

## Structure
```
index.html          markup + SVG icon sprite
css/                variables (tokens) · base · layout · components · responsive
js/                 utils · storage · ui (rendering) · app (state + events)
assets/             favicon
```
